# Cloud Security & Azure Incident Investigation

## Project Type
Simulated Cloud Security Investigation

## Role
Junior Cloud Security Analyst

## Platform
Microsoft Azure

## Focus
Cloud Security Monitoring, Identity Security, Access Control, Incident Detection, and Response

---

## Incident Overview

A cloud security monitoring system generated an alert involving suspicious activity within an organization's Azure environment.

The investigation focused on identifying the source of the activity, determining whether unauthorized access occurred, and recommending appropriate containment measures.

---

## Investigation Objectives

- Review suspicious cloud activity
- Investigate authentication events
- Identify potentially compromised accounts
- Analyze unusual access patterns
- Assess security impact
- Recommend containment and remediation actions

---

## Initial Findings

The investigation identified unusual authentication activity involving a cloud account.

The activity originated from an unfamiliar location and was inconsistent with the user's normal access behavior.

This activity was treated as a potential account compromise.

---

## Indicators of Compromise

- Unusual login location
- Abnormal authentication behavior
- Unexpected cloud resource access
- Suspicious account activity
- Potential unauthorized access

---

## Analyst Assessment

The activity presented a potential identity and access security risk within the Azure environment.

Further investigation was required to determine whether the account had been compromised and whether additional cloud resources were accessed.

---

## Recommended Response

1. Verify the user's identity and recent activity.
2. Review Azure authentication and audit logs.
3. Revoke active sessions if compromise is confirmed.
4. Reset affected credentials.
5. Enforce Multi-Factor Authentication (MFA).
6. Review account permissions and role assignments.
7. Investigate accessed cloud resources.
8. Continue monitoring for related activity.
9. Document and escalate the incident.
